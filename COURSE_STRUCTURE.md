## 0. Honest scope

This is a **curriculum map**, not a claim that all of it exists yet. Only **Module 1 (chapters 1.1–1.4)** is fully authored to the quality bar. Everything below is the **target** for the longest serious reading course we intend to build.

| Layer | Grand Pathway target | Shipped |
| --- | ---: | ---: |
| Phases (CEFR bands) | 6 | 1 started |
| Modules (themes) | **36** | 1 deep + 35 shells |
| Units (grammar arcs) | **180** | 4 (inside Module 1) |
| Sub-chapters (study sessions) | **540** | **4** |
| Tracked lemmas | **~12,000** | ~300 |
| Guided reading words | **~450,000** | ~1,100 |
| Grammar Rulebook pages | **~200** | 8 |

**Old plan (12 × 8 = 96 chapters)** is folded into this map: each old “chapter” ≈ one **Unit**; each **Sub-chapter** is half to a third of a week’s study.

## 1. Hierarchy (new default)

```
Course — Grand Pathway (~36–48 months)
 └── Phase (CEFR band · ~6–8 months)
      └── Module (theme · ~4–6 weeks · 5 units)
           └── Unit (grammar + vocab arc · ~1 week)
                └── Sub-chapter (one deep study session · 45–90 min)
                     ├── Brief (theory + traps)
                     ├── Reading (300–1,200 words)
                     ├── Dialogue (12–20 turns)
                     ├── Vocabulary (40–80 new lemmas)
                     ├── Exercises (22–30)
                     └── Rulebook unlock (when applicable)
```

### Sub-chapter roles (A · B · C)

Every unit has **three** sub-chapters:

| Code | Role | Focus |
| --- | --- | --- |
| **A** | **Learn** | New grammar + core vocabulary introduced in reading |
| **B** | **Apply** | Same grammar in new context; more drills; dialogue stress-test |
| **C** | **Integrate** | Mixed practice, spiral from prior units, short checkpoint reading |

**Naming:** `Phase.Module.Unit.Sub` → e.g. **P1.M03.U2.B** = Phase 1, Module 3, Unit 2, Apply.

**Legacy map:** Current shipped **1.1–1.4** = **P1.M01.U1.A–U4.A** (Units 1–4 only have `.A` authored; `.B`/`.C` are planned expansions).

### Quality bar (every sub-chapter)

| Block | Minimum |
| --- | --- |
| Theory brief | 900+ characters, nuance traps |
| Reading | 220+ words (A/B); 400+ (C checkpoints) |
| Dialogue | 12+ turns |
| New lemmas | 40–80 (A), 25–50 (B), 15–35 spiral (C) |
| Exercises | 22–30, grammar/vocab only (no story-memory) |
| Study time | 45–90 minutes |

### Tracks

| Track | Calendar | Pace | End level |
| --- | ---: | --- | --- |
| **Relaxed** | 48 months | 3 sub-chapters / week | Strong B2 |
| **Standard** | 36 months | 4 sub-chapters / week | **C1 reading** |
| **Intensive** | 24 months | 6 sub-chapters / week | C1 + annex exposure |
