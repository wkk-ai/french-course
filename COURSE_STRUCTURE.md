## 1. Hierarchy

```
Course — Complete Edition (~48–60 months)
 │
 ├── P0 · Placement (one-time · ~20 min)
 │
 ├── Grand Pathway — Phases I–VI (~42 months)
 │    └── Phase (CEFR band · ~7 months)
 │         ├── Module (theme · ~5 weeks · 5 units)
 │         │    └── Unit (grammar arc · ~1 week)
 │         │         ├── A · Learn      (new grammar + core vocab)
 │         │         ├── B · Apply      (new context + drills)
 │         │         ├── C · Integrate  (spiral + checkpoint reading)
 │         │         ├── D · Prove      (10–15 min gate — no hints)
 │         │         └── μ · Micro-skill (5–10 min bridge — optional same week)
 │         └── Phase Capstone (end of phase · 1–2 sessions)
 │
 ├── Specialty Tracks — parallel annex (~6–12 months, any time after B1)
 │    └── Same A/B/C/D unit shape; readings skew to domain
 │
 ├── In The Wild — ongoing (import + level + Review enqueue)
 │
 └── Phase VII · C2 Stretch (optional · ~12 months after C1)
      └── 6 modules · literary / legal / academic depth
```

### Sub-chapter roles (A · B · C · D)

| Code | Role | Focus | Study time |
| --- | --- | --- | ---: |
| **A** | **Learn** | New grammar, core lemmas, rulebook unlock | 45–90 min |
| **B** | **Apply** | Same grammar, new scene; dialogue stress-test | 45–75 min |
| **C** | **Integrate** | 20% spiral; mixed drills; checkpoint reading | 45–75 min |
| **D** | **Prove** | Timed mixed quiz; short cold reading; “explain the rule” | 10–15 min |

**Prove (D) is mandatory** to mark a unit complete. Failing D reopens B/C remediation — not a full replay of A.

**Naming:** `P1.M03.U2.B` = Phase 1, Module 3, Unit 2, Apply.

### Every unit includes (non-negotiable anatomy)

| Component | Requirement |
| --- | --- |
| **Grammar** | Introduced A → drilled B → spiraled C → tested D |
| **Lemmas** | 40–80 new (A); 25–50 (B); 15–35 spiral (C); D tests prior unit lemmas |
| **Collocations** | **8–12 fixed chunks** per unit (e.g. *avoir faim*, *faire une erreur*) — own Review deck tag `chunk` |
| **Meanings-first theory** | Brief lists **lemma = English** for every content word **before** that word appears in a grammar example |
| **Register trio** | Same idea in **soutenu / courant / familier** (read-only for familier until Phase V) |
| **Francophonie lens** | Each module tags one region (France default; rotate QC · SN · MA · BE · GP · RE) |
| **Rulebook** | 1–3 rules unlock on **A** complete; each rule has **Try it** drills tied to that unit |
| **Spiral** | ≥20% of exercises in B/C pull from prior units in the phase |
| **No story-memory** | Quiz French, never plot recall; no proper-noun flashcards |

### Micro-skill bridges (μ)

Short **5–10 min** slot between units (same week as D, or rest day):

| Phase | Examples |
| --- | --- |
| I | Fast numbers · dates · spelling names · *M./Mme* · silent letters |
| II | Past participle spot-check · time phrases · *y/en* quick fire |
| III | Subjunctive trigger flash · email openings · headline parsing |
| IV | Connector choice · passive spot · data/table reading |
| V | Register swap (one sentence) · idiom gloss · PS recognition |
| VI | Form field labels · legal boilerplate · synthesis outline |

~**175** micro-skills across the core path (one per unit boundary). Not gated for progression — strongly recommended.

## 2. Placement (P0)

**Before Module 1.** ~20 minutes. Not graded for shame — routes the learner.

| Block | Content |
| --- | --- |
| Grammar radar | 15 items (present, past, articles, pronouns) |
| Vocab sample | 30 items tagged by frequency band |
| Short reading | 120-word passage + 5 comprehension items |
| Output | Start M01 · skip to M07 · skip to M13 · **relaxed / standard / intensive** track |

**Skip-ahead rule:** scoring ≥85% on a phase diagnostic unlocks starting at that phase’s first module (prior lemmas enqueued as “seen” for Review, not mastered).

## 9. Rulebook lockstep

| Rule | Detail |
| --- | --- |
| Unlock | Each **Learn (A)** completes → 1–3 `ruleSlugs` pages unlock |
| Depth | Quick / Deep / Examples / **Try it** tabs (see `docs/rules/`) |
| Try it | ≥6 drills per rule; map to `remediationCategories` |
| No orphans | Every rule tied to ≥1 unit; every unit A links ≥1 rule |
| Hidden until unlock | Locked rules invisible in list (no title spoilers) |
| Prove | D may include 2–3 rule-level items from current unit |

**~220 rules** across Phases I–VI (+30 in Phase VII).
